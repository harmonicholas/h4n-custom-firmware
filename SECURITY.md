# Reporting problems

For firmware hangs, audio corruption or update problems, open a minimal issue with model/version/routing details and steps to reproduce. Do not publish device dumps, firmware binaries or private recordings.

For a vulnerability with sensitive details, use GitHub private vulnerability reporting if the maintainer has enabled it. If unavailable, first open an issue requesting a private contact without disclosing exploit details. Do not assume this repository has a staffed or guaranteed response process.
